            Identifying food

            Reading text works offline and needs no key, but it only knows labels and receipts. To identify loose food by sight, the app can send the photo to Claude with your own Anthropic API key. Photos then leave the phone only for that request; the key is stored on this device.

            About

            Text is read on your phone with Tesseract, an open-source recogniser bundled with the app, so it works offline. Identifying food by sight uses Claude and only happens when you have entered an API key above.
